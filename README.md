# sales-tracker

تطبيق ويب بسيط لتسجيل عمليات البيع لكل عميل وتصدير ملفات Excel.

يتوفر الآن إصدارين في المستودع:
- Node.js (server.js) — الإصدار الأصلي.
- Python (app.py) — إصدار جديد يعمل بـ Flask + SQLite + openpyxl.

تشغيل الإصدار بالبايثون (Windows 7 أو أحدث)

1. تأكد أن لديك Python 3.8+ منصّبًا. إن لم يكن مثبتًا، نزّل من https://www.python.org/downloads/ (اختر إصدار يدعم Win7 إذا لزم).
2. افتح PowerShell في مجلد المشروع.
3. أنشئ بيئة افتراضية وتفعيلها:
   - python -m venv .venv
   - .\.venv\Scripts\activate
4. ثبّت الاعتماديات:
   - pip install -r requirements.txt
5. شغّل التطبيق:
   - python app.py
6. افتح المتصفح على:
   - http://localhost:3000

ملاحظات حول القاعدة والملفات
- قاعدة البيانات هي data.db في جذر المشروع وتُنشأ تلقائيًا عند تشغيل التطبيق لأول مرة.
- ملفات Excel تُولد في الذاكرة وتُرسل كتحميل للمستخدم.

مزايا هذا الإصدار
- يعمل بسهولة مع Python على أنظمة قديمة (Win7/Win8) بشرط وجود بايثون مناسب.
- لا حاجة لأدوات بناء C++ لأننا نستخدم sqlite3 المضمن في بايثون وopenpyxl.

إذا تريد، أستطيع:
- إزالة نسخة Node.js من المستودع أو نقلها إلى مجلد legacy/.
- إضافة ملف إعداد خدمة Windows (با NSSM أو متطلبات pm2-windows-service) لتشغيل التطبيق كخدمة.
- تعديل الواجهة أو إضافة حقول جديدة.
