# sales-tracker

تطبيق ويب بسيط لتسجيل عمليات البيع لكل عميل وتصدير ملفات Excel.

الملف يوفّر:
- واجهة ويب بسيطة لإضافة عملاء وتسجيل المبيعات.
- تصدير ملف Excel منفصل لكل عميل.
- تصدير ملف Excel مجمع يحوي صفحة ملخص ثم ورقة لكل عميل.

تشغيل محلي:

1. انسخ المشروع أو شغّل على جهازك:
   - git clone https://github.com/elmasrysatstore-maker/-.git
   - cd -
2. ثبّت الحزم:
   - npm install
3. شغّل الخادم:
   - npm start
4. افتح المتصفح على http://localhost:3000

ملاحظات:
- قاعدة البيانات ملفية (data.db) موجودة في جذر المشروع.
- اضبط اعتماديات أو غيّر SQLite إلى MongoDB إذا رغبت.
