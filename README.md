# sales-tracker

تطبيق ويب بسيط لتسجيل عمليات البيع لكل عميل وتصدير ملفات Excel.

يتوفر الآن إصدارين في المستودع:
- Node.js (server.js) — الإصدار الأصلي.
- Python (app.py) — الإصدار المُحدّث يعمل بـ Flask + SQLite + openpyxl.

تم إضافة حقول جديدة للمبيعات:
- رمز المنتج (product_code)

ميزة توليد رقم الفاتورة تلقائيًا
- رقم الفاتورة يُنشأ تلقائيًا عند تسجيل كل عملية من تاريخ العملية وترتيبها في ذلك اليوم.
- الصيغة: INV-YYYYMMDD-####  (مثال: INV-20260706-0001)
- يتم حساب الرقم بترقيم العمليات الموجودة مسبقًا في نفس تاريخ الحقل `date` وإضافة 1 للترتيب.

تشغيل الإصدار بالبايثون (Windows 7 أو أحدث)

1. تأكد أن لديك Python 3.8+ منصّبًا. إن لم يكن مثبتًا، نزّل من https://www.python.org/downloads/ (اختر إصدار يدعم Win7 إذا لزم).
2. افتح PowerShell في مجلد المشروع.
3. أنشئ بيئة افتراضية وتفعيلها:
   - python -m venv .venv
   - .\\.venv\\Scripts\\activate
4. ثبّت الاعتماديات:
   - pip install -r requirements.txt
5. شغّل التطبيق:
   - python app.py
6. افتح المتصفح على:
   - http://localhost:3000

نقاط API المحدثة
- POST /api/sales: لا ترسل رقم الفاتورة — سيُنشأ تلقائيًا. حقل `product_code` ما زال متاحًا للإرسال.

هام: الترقية من نسخة سابقة
- عند تشغيل app.py لأول مرة، سيحاول الكود إنشاء أعمدة جديدة في جدول sales إذا لم تكن موجودة بالفعل (يستخدم ALTER TABLE لإضافة invoice_number وproduct_code). لا تحتاج لمسح قاعدة البيانات القديمة، لكن خذ نسخة احتياطية قبل الاستخدام الإنتاجي.
